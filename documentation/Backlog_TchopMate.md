# 📒 Backlog TchopMate – Version Markdown Optimisée

## 🎯 Introduction
L'application TchopMate permet aux étudiants de commander des plats à l’avance dans le restaurant universitaire via une interface web simple, avec système de QR code unique pour le retrait. Le projet dure 8 semaines (14 sept. – 9 nov. 2025), organisé en 4 sprints.

## 🗂️ Objectifs du backlog
- Présenter clairement la feuille de route.
- Mettre l’accent sur les besoins étudiants et restaurant.
- Détailler les user stories et leur priorité.

## 🏗️ Structure des Sprints
- **4 sprints de 2 semaines**
- Capacité : ~10–12 points / sprint

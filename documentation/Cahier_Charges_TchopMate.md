---

# 2. Présentation du projet
Application web pour :
- Consulter menus
- Commander
- Payer
- Retirer via QR code
- Dashboard staff/admin

---

# 3. Définition du problème
Files d’attente longues, gestion manuelle inefficace, absence de statistiques.

---

# 4. Besoins fonctionnels (résumé)
- Consultation du menu
- Commande + créneau
- Paiement MoMo ou comptoir
- Scan QR
- Gestion menus / stocks
- Suivi statistiques

## Besoins non fonctionnels
- Sécurité
- Performance
- Ergonomie
- Scalabilité

---

# 5. Objectifs
- Réduire le temps d’attente
- Optimiser la gestion
- Moderniser l’image de l’université

---

# 6. Solution proposée
Architecture web moderne :
- **Frontend** : Next.js + Tailwind
- **Backend** : Supabase
- **QR codes**
- **Mobile Money** (optionnel MVP)

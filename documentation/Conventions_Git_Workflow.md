# 🛠️ Conventions Git & Workflow – TchopMate

## Branches principales
- **main** → Production
- **develop** → Intégration

## Branches de travail
Format : `type/nom-tache`

Types :
- feature/
- fix/
- docs/
- test/
- refactor/

---

# Workflow Git
1. Créer branche depuis `develop`
2. Commits clairs (`feat(menu): add daily menu`)
3. Push
4. Pull Request vers `develop`
5. Review → merge
6. Fin sprint : merge develop → main (Scrum Master)

---

# Bonnes pratiques
- Mises à jour avant création de branche
- Petits commits
- 1 PR = 1 fonctionnalité
